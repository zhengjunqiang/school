## 二、检测概述

本次检测针对海洋牧场生态监测系统中的**终端设备**与**网关设备**，依据项目技术指标要求，对关键性能参数进行测试验证，旨在确认设备是否满足“低成本、易维护、高可靠”的国产化环境监测需求，为系统后续部署提供技术依据。

## 三、终端设备检测

### 3.1 检测依据

项目技术指标要求及《海洋牧场终端设备测试规范》。

### 3.2 检测指标与要求

| 检测指标 | 要求 |
|----------|------|
| 传输距离 | ≥5000米 |
| 休眠功耗 | ≤2uA |
| 带宽 | ≥20kbps |

### 3.3 检测设备与工具

| 设备名称 | 型号/规格 | 用途 |
|----------|-----------|------|
| Lora主机/从机 | - | 传输距离、带宽测试 |
| 高精度电流测试仪器 | - | 休眠功耗测试 |
| Lora模组 | ATK-MW1268D | 终端核心通信模块 |
| 串口调试工具 | - | 配置设备参数 |

### 3.4 检测方法

#### 3.4.1 传输距离测试

1. 配置Lora主机与从机：网络ID设为1，地址ID设为65535，工作模式设为“一般模式”；
2. 将主机与从机的发射信号功率调至最大（22dBm），空口速率调至最低；
3. 分别在1000米、3000米、5000米、5500米距离处进行数据传输测试，记录通信成功率。

#### 3.4.2 休眠功耗测试

1. 配置终端设备进入“休眠模式”，通过高精度电流测试仪器接入设备正负极；
2. 串口参数设置：波特率115200、数据位8、无校验、停止位1；
3. 持续监测并记录设备休眠状态下的电流值，取10次测量平均值。

#### 3.4.3 带宽测试

1. 配置Lora主机与从机：发射功率调至最大（22dBm），空口速率调至最大（62.5Kbps）；
2. 连续发送100MB测试数据，记录数据传输总时长，计算实际带宽。

### 3.5 检测结果与分析

| 检测指标 | 测试结果 | 是否符合要求 | 备注 |
|----------|----------|--------------|------|
| 传输距离 | 5500米处通信成功率100% | 是 | 满足≥5000米要求 |
| 休眠功耗 | 1.9uA | 是 | 低于≤2uA要求（ATK-MW1268D模组最低功耗1.9uA@5V） |
| 带宽 | 25kbps | 是 | 高于≥20kbps要求 |

**分析**：终端设备各项指标均达到或优于项目要求，传输稳定性、低功耗性能及数据传输效率满足海洋牧场远程监测场景需求。

## 四、网关设备检测

### 4.1 检测依据

项目技术指标要求及《海洋牧场网关设备测试规范》。

### 4.2 检测指标与要求

| 检测指标 | 要求 |
|----------|------|
| 接入量 | ≥1000个终端设备 |
| 平台鉴权 | 通过SM2国密鉴权 |

### 4.3 检测设备与工具

| 设备名称 | 型号/规格 | 用途 |
|----------|-----------|------|
| Lora网关 | - | 接入终端设备测试 |
| 云平台测试环境 | - | 并发接入及鉴权测试 |
| SM2鉴权文件 | - | 国密鉴权验证 |
| 终端模拟器 | - | 模拟多终端接入 |

### 4.4 检测方法

#### 4.4.1 接入量测试

1. 配置Lora网关为“网关模式”，网络ID与终端设备保持一致；
2. 通过终端模拟器模拟1000个、1200个终端设备接入网关，记录网关连接状态及数据接收成功率；
3. 验证网关对多终端数据的汇聚与上传能力。

#### 4.4.2 SM2国密鉴权测试

1. 在网关平台导入SM2国密鉴权文件，执行鉴权操作；
2. 未导入鉴权文件时，尝试查看传感器设备数据，记录访问权限；
3. 鉴权成功后，验证设备数据查看、远程配置等功能的可用性。

### 4.5 检测结果与分析

| 检测指标 | 测试结果 | 是否符合要求 | 备注 |
|----------|----------|--------------|------|
| 接入量 | 1200个终端接入时，连接成功率100%，数据接收正常 | 是 | 远超≥1000个接入量要求 |
| SM2国密鉴权 | 导入鉴权文件后鉴权成功，可正常访问设备数据；未导入时无访问权限 | 是 | 符合国密安全要求 |

**分析**：网关设备接入能力冗余充足，可支持超量终端设备接入；SM2国密鉴权机制有效，保障了平台数据传输与访问的安全性。

## 五、检测结论

本次检测的海洋牧场**终端设备**（传输距离、休眠功耗、带宽）与**网关设备**（接入量、SM2国密鉴权）各项性能指标均符合项目技术要求，设备运行稳定、可靠，可用于海洋牧场生态环境监测系统的部署与应用。
